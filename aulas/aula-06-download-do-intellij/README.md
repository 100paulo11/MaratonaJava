\# Aula 06 — Download do IntelliJ IDEA



\## 📚 Tema



Download e instalação da IDE IntelliJ IDEA para desenvolvimento em Java.



\## 🧠 O que aprendi



Uma IDE (Integrated Development Environment) é um ambiente de desenvolvimento

que reúne ferramentas para facilitar a criação de programas.



O IntelliJ IDEA é uma IDE utilizada para desenvolvimento em Java e oferece

recursos como editor de código, compilação, execução e ferramentas para

organização e desenvolvimento dos projetos.



\## 💻 Experiência prática



Baixei e instalei o IntelliJ IDEA no computador.



A instalação foi realizada com sucesso e a IDE está pronta para ser utilizada

nas próximas aulas da Maratona Java.



\## 💡 Minha observação



Até a Aula 05, realizei a compilação e execução dos programas manualmente pelo

terminal.



A partir desta aula, vou começar a utilizar uma IDE para facilitar o

desenvolvimento dos programas e entender como ela auxilia durante o processo

de programação.
