\# Aula 21 - else if



\## Objetivo



Aprender a utilizar `else if` para trabalhar com múltiplas condições e permitir que o programa escolha entre diferentes possibilidades.



\---



\## O que é o else if?



O `else if` permite adicionar uma nova condição depois de um `if`.



Enquanto o `if` e o `else` permitem trabalhar com dois caminhos, o `else if` permite criar várias possibilidades.



Estrutura básica:



```java

if (condicao1) {

&#x20;   // executado se a primeira condição for verdadeira

} else if (condicao2) {

&#x20;   // executado se a segunda condição for verdadeira

} else {

&#x20;   // executado se nenhuma condição anterior for verdadeira

}







Conceitos aprendidos

Estrutura if

Estrutura else if

Estrutura else

Múltiplas condições

Ordem de avaliação das condições

Execução do primeiro bloco cuja condição seja verdadeira

Criação de diferentes caminhos de execução
