\# Aula 05 — Compilação Manual



\## 📚 Tema



Compilação e execução de um programa Java utilizando o terminal, sem depender de uma IDE.



\## 🧠 O que aprendi



Um programa Java precisa ser compilado antes de ser executado.



O comando `javac` é responsável por compilar o arquivo `.java` e gerar um

arquivo `.class`, que contém o bytecode.



Por exemplo:



```bash

javac Main.java


## 💻 Experiência prática

Criei um programa simples em Java e realizei a compilação manualmente pelo
terminal.

Utilizei o comando:

```bash
javac Main.java


A compilação gerou o arquivo Main.class.

Depois executei o programa com:

java Main

O resultado foi:

Compilação manual funcionando!

Essa prática me ajudou a entender na prática a diferença entre compilar e
executar um programa Java.
