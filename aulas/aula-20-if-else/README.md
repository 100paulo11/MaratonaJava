\# Aula 20 - if e else



\## Objetivo



Aprender a utilizar as estruturas condicionais `if` e `else` para fazer o programa escolher entre dois caminhos diferentes.



\---



\## O que é o if e else?



O `if` executa um bloco de código quando uma condição é verdadeira.



O `else` executa outro bloco quando a condição do `if` é falsa.



A estrutura básica é:



```java

if (condicao) {

&#x20;   // executado se a condição for verdadeira

} else {

&#x20;   // executado se a condição for falsa

}





Exemplo

int idade = 16;



if (idade >= 18) {

&#x20;   System.out.println("Maior de idade");

} else {

&#x20;   System.out.println("Menor de idade");

}
