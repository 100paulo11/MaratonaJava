\# Aula 07 — Conhecendo a IDE



\## 📚 Tema



Conhecendo a interface e os principais recursos da IDE IntelliJ IDEA.



\## 🧠 O que aprendi



Uma IDE facilita o desenvolvimento de programas porque reúne diversas

ferramentas em um único ambiente.



O IntelliJ IDEA possui recursos para edição de código, execução de programas,

organização de arquivos, identificação de erros e auxílio durante a

programação.
