\# Aula 08 — Organizando o Código em Pacotes



\## 📚 Tema



Organização das classes Java utilizando pacotes (`package`).



\## 🧠 O que aprendi



Packages são utilizados para organizar as classes de um projeto Java.



Eles ajudam a manter o código organizado e também evitam conflitos entre

classes que possuem o mesmo nome.



Um package pode ser declarado no início de uma classe utilizando:



```java

package aula08;
