\## 🔀 O que é `switch`?



O `switch` permite verificar o valor de uma variável e executar o `case` correspondente.



Estrutura básica:



```java

switch (variavel) {



&#x20;   case valor:

&#x20;       // código

&#x20;       break;



&#x20;   case outroValor:

&#x20;       // código

&#x20;       break;



&#x20;   default:

&#x20;       // código caso nenhum case seja encontrado

}



Ou seja, \*\*um único par de ``` por bloco de código\*\*.
