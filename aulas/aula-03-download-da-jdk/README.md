\# Aula 03 — Download da JDK



\## 📚 Tema



Download e instalação da JDK (Java Development Kit).



\## 🧠 O que aprendi



A JDK (Java Development Kit) é o conjunto de ferramentas necessário para

desenvolver programas em Java.



Ela contém ferramentas como o compilador `javac`, que transforma o código

Java em bytecode, e o comando `java`, utilizado para executar os programas.



A JDK é necessária para quem quer desenvolver aplicações Java, pois fornece

as ferramentas necessárias para escrever, compilar e executar código.



\## ☕ Versão da JDK



A versão da JDK apresentada nesta aula é a JDK 15.



A JDK é atualizada ao longo do tempo, por isso existem versões mais recentes.

O importante é utilizar uma versão compatível com os exemplos e conteúdos do

curso.



\## 💡 Minha observação



Entendi que a JDK é a ferramenta que permite desenvolver em Java.



Ela fornece recursos importantes para escrever, compilar e executar programas

Java, sendo uma parte fundamental do ambiente de desenvolvimento.



Também entendi que existem diferentes versões da JDK e que é importante saber

qual versão está sendo utilizada no projeto.
