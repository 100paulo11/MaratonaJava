\# Aula 19 - Estrutura Condicional if



\## Objetivo



Aprender a utilizar a estrutura condicional `if` para executar um bloco de código somente quando uma condição for verdadeira.



\---



\## O que é o if?



O `if` permite que o programa tome decisões.



Sua estrutura básica é:



```java

&#x20;   // código executado se a condição for verdadeira

}
