\# Aula 24 - Exercício de Operadores Lógicos



\## Objetivo



Praticar os operadores lógicos `\&\&`, `||` e `!` junto com estruturas condicionais `if` e `else`.



Nesta aula, os conceitos aprendidos anteriormente são combinados em um exercício mais próximo de uma situação real.



\---



\## Exercício 1 - Idade e ingresso



```java

int idade = 20;

boolean possuiIngresso = true;



if (idade >= 18 \&\& possuiIngresso) {

&#x20;   System.out.println("Pode entrar na festa");

} else {

&#x20;   System.out.println("Não pode entrar na festa");

}



Conceitos aprendidos

Operador lógico \&\& (AND)

Operador lógico || (OR)

Operador lógico ! (NOT)

Estruturas if e else

Valores booleanos

Combinação de operadores relacionais e lógicos

Criação de condições mais complexas
