\# Aula 01 — O que esperar do curso



\## 📚 Tema
O que esperar da Maratona Java Virado no Jiraya.



\## 🎯 Objetivo da aula



Entender a proposta da Maratona Java e ter uma visão geral de como será o

aprendizado durante o curso.



A ideia é começar pelos fundamentos do Java e evoluir gradualmente para

conceitos mais avançados da linguagem.



\## 🧠 O que aprendi



A Maratona Java tem como objetivo ensinar Java desde os conceitos básicos até

assuntos mais avançados.



Entendi que o aprendizado será gradual, começando pela base da linguagem e

evoluindo conforme as aulas avançam.



Também entendi que não basta apenas acompanhar as aulas: é importante praticar,

escrever código e revisar os conceitos aprendidos.



\## 💡 Minha observação



Estou começando a Maratona Java do zero e vou utilizar este repositório para

registrar minha evolução durante o curso.



Meu objetivo é entender os conceitos, praticar e futuramente utilizar esse

conhecimento na criação dos meus próprios projetos.
